Abstract & Overview

A web browser is the fundamental client application that retrieves, parses, and renders information resources on the World Wide Web. From Sir Tim Berners-Lee's first browser in 1990 to modern multi-process engines like Chromium, browsers have evolved from static document viewers into full-scale application operating environments.

  • Document Object Model (DOM)
  • Rendering Engine (Blink, WebKit, Gecko)

  • Process Sandboxing
