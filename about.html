Purpose of This Milestone Project

This website stands as the Milestone #1 deliverable for IT 3203 Intro to Web Development. While future milestones will introduce client-side JavaScript form processing and responsive mobile design, this initial phase establishes the foundational HTML and CSS structure of the research site. By combining six interconnected HTML pages with a single shared stylesheet, the site demonstrates how static web files are authored at design time, hosted on a web server, and rendered in the browser.

This website is a class project for IT 3203 Intro to Web Development at Kennesaw State University.
