About This Project

This multi-page informational website was developed for Project Milestone #1 in IT 3203. It presents research on the historical evolution, rendering engines, and multi-process security architecture of web browsers using hand-coded HTML5 and a single shared CSS stylesheet.

This website is a class project for IT 3203 Intro to Web Development at Kennesaw State University.
