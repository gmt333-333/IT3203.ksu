Modern Web Browser Architecture

Modern web browsers operate like mini-operating systems. In a client-server web architecture, the browser acts as the client software that sends HTTP requests to a web server and renders the returned HTML, CSS, and JavaScript files into an interactive visual interface.

Core Subsystem Components

  • User Interface (UI): The address bar, back/forward buttons, bookmark menu, and tab bar.
  • Browser Engine: Coordinates actions between the User Interface and the Rendering Engine.
  • Rendering Engine: Parses HTML and CSS to build the Document Object Model (DOM) tree and paint pixels to the screen (e.g., Blink, WebKit, Gecko).
  • Networking Layer: Handles HTTP/HTTPS requests, DNS lookups, and caching.
  • JavaScript Interpreter: Compiles and executes client-side JavaScript code (e.g., Chrome's V8 engine).
  • Data Persistence: Manages local storage, cookies, IndexedDB, and session data.
